Core Architecture

엔지니어링 특성 및 주요 기능

불필요한 알림 노이즈를 줄이고 신뢰성 높은 전달 환경을 구현했습니다.

백그라운드 동기화 서비스

Android Foreground Service와 저전력 루틴을 결합하여 화면 잠금 상태에서도 안정적으로 알림을 감지합니다.

스와이프 지움 상태 영속화

사용자가 시스템 상단 알림 바에서 밀어서 제거한 항목을 추적하여 서비스 재시작 시 동일 알림의 중복 생성을 원천 차단합니다.

계정별 세부 카테고리 필터

유저 단위로 댓글, 좋아요, 팔로우, 공유 등 원하는 알림 유형을 개별적으로 선택하여 수신 여부를 제어합니다.

비활성 시간대 스케줄러 (DND)

설정된 지정 시간대에는 네트워크 폴링을 자동으로 일시 중지하여 불필요한 배터리 소모와 수면 중 방해를 방지합니다.

로컬 SQLite 아카이브 보관

시스템 알림에서 소멸된 지난 내역도 기기 내 Room DB에 정형 데이터로 영구 보존되어 언제든 열람 및 검색이 가능합니다.

검증된 도메인 딥링크 이동

알림 클릭 시 엔트리 공식 화이트리스트 도메인(playentry.org)만을 검증한 뒤 해당 대상 페이지로 안전하게 직접 연결합니다.

Security & Isolation

데이터 격리 및 보안 모델

Entify는 사용자 계정의 보안과 데이터 무결성을 최우선 원칙으로 설계되었습니다.

완전한 클라이언트 지향 아키텍처

중간 프록시나 수집 서버가 전혀 존재하지 않습니다. 모든 GraphQL 통신은 사용자의 단말기와 공식 엔트리 엔드포인트 간의 직접적인 암호화(TLS 1.3) 터널로만 전송됩니다.

안드로이드 샌드박스 내부 격리

로그인 세션 토큰 및 로컬 아카이브 데이터베이스는 타 애플리케이션의 접근이 시스템 레벨에서 차단된 앱 내부 전용 저장 영역에 격리 저장됩니다.

소스코드 공개 및 검증성

Entify의 모든 소스코드는 공개 검증이 가능한 Source-Available License v1.0 하에 제공되어, 트래커나 백도어 등 잠재적 보안 결함이 없음을 누구나 확인할 수 있습니다.

Deployment

설치 및 초기 설정

표준 Android 패키지 설치 절차에 따라 진행됩니다.

01

패키지 다운로드

상단 배포 버튼을 통해 최신 릴리즈 APK 패키지를 단말기에 다운로드합니다.

02

패키지 실행 및 권한 허용

다운로드된 파일을 실행하고 단말기 보안 안내에 따라 설치를 완료합니다.

03

계정 인증 및 감시 시작

앱 내에서 엔트리 계정으로 1회 인증을 완료하면 백그라운드 서비스가 활성화됩니다.
