엔트리 알림을
놓치지 않도록

Entify는 엔트리 알림을 기기에서 확인해 Android 알림과 로컬 보관함으로 정리합니다. 엔트리 공식 앱이 아니며, 개발자가 운영하는 중계 서버로 로그인 정보나 세션을 보내지 않습니다.

설치 전에 보안 및 개인정보 답변 먼저 보기 Entify APK 다운로드 v1.2.0 (Android 7.0 이상, Play 스토어 외부 설치)

Android에 설치하기

다운로드 직후 아래 순서대로 진행하세요. 휴대전화 제조사에 따라 메뉴 이름은 조금 다를 수 있습니다.

APK 다운로드 확인

다운로드한 파일 이름이 Entify.apk인지 확인합니다.

이 출처만 잠시 허용

Android가 요청하면 다운로드에 사용한 브라우저 또는 파일 앱에만 “이 출처의 앱 설치”를 허용합니다. 기기 전체 보안 기능을 끌 필요는 없습니다.

설치 후 허용 해제

설치가 끝나면 해당 출처의 설치 허용을 다시 끄고 Entify를 실행합니다. Play Protect 우회는 권하지 않습니다.

공식 엔트리 페이지에서 로그인

앱 안에 표시되는 playentry.org 로그인 화면에서 로그인하고 필요한 알림 권한을 선택합니다.

TRUST ARCHITECTURE

신뢰해야 하는 범위를 줄였습니다

비밀번호를 별도 서버로 보내지 않고, 세션 보관·페이지 통신·배포 검증을 서로 다른 경계로 나누어 한 계층의 문제가 전체 권한으로 번지지 않도록 설계했습니다.

01

공식 페이지 로그인

로그인은 앱이 만든 입력 폼이 아니라 https://playentry.org 페이지에서 진행됩니다.

02

기기 안에서 보호

세션·토큰과 알림 제목·본문·원본 payload는 Android Keystore 키로 암호화됩니다.

03

엔트리로 직접 통신

인증 자료는 Entify 중계 서버를 거치지 않고 엔트리 HTTPS API 요청에만 사용됩니다.

04

배포 파일 검증

릴리스 버전, APK SHA-256과 서명 인증서 지문을 함께 공개합니다.

WebView 경계

정확한 HTTPS 출처, 최상위 프레임, 현재 경로와 메시지 크기를 모두 검사합니다.

기기 노출 방어

백업·화면 캡처·최근 앱 미리보기·가려진 터치와 Android 12 이상 오버레이를 제한합니다.

응답 처리 방어

API·HTML·이미지 크기 상한, 이미지 픽셀 수와 SVG 위험 선언을 검사합니다.

공개된 한계

루팅·후킹·손상된 OS와 공식 출처 자체의 XSS를 완전히 무효화한다고 주장하지 않습니다.

필요한 알림은 선명하게, 기록은 그대로

댓글, 좋아요, 팔로우, 리메이크, 공유, 시스템 알림을 의미에 맞게 분류하고, 실제 사용자 프로필과 작품 썸네일을 함께 보여줍니다.

BACKGROUND

백그라운드 알림

화면이 꺼져 있어도 포그라운드 서비스가 새 알림을 확인합니다.

ARCHIVE

원본 알림 보관함

영구 수집은 기본 동작입니다. 인증값을 제외한 수신 원문과 메타데이터를 기기 안에 보관합니다.

CONTROL

사용자별 알림 관리

사용자와 알림 종류별로 피드 표시 여부를 세밀하게 조절합니다.

보안 및 개인정보 질문에 답합니다

“왜 로그인 세션이 필요한가?”, “개발자에게 전송되는가?”, “APK를 믿어도 되는가?”처럼 설치 전에 확인해야 할 내용을 숨기지 않았습니다.

중요: 어떤 앱도 위험 0%를 보장할 수는 없습니다. Entify는 공격 표면을 줄이고 세션을 암호화하지만, 루팅, 악성 앱, 손상된 OS 환경에서는 Android 자체의 보호가 약해질 수 있습니다.
아이디와 비밀번호를 Entify가 저장하나요?

아니요. 로그인 입력 화면은 https://playentry.org의 공식 로그인 페이지이며, Entify는 비밀번호를 별도 파일이나 서버에 저장하지 않습니다. 공식 페이지가 만든 로그인 결과만 사용합니다.

쿠키, 로그인 세션, 토큰은 왜 필요한가요?

엔트리의 비공개 알림은 로그인한 사용자만 조회할 수 있어 세션 쿠키, CSRF 값, x-token이 필요합니다. Entify는 공식 로그인 이후 이 값을 읽어 자동 로그인 유지와 알림 API 인증에만 사용합니다. API 요청 주소, 헤더, 본문 형식은 엔트리 호환성을 위해 임의로 변형하지 않습니다.

세션이 개발자 서버나 분석 서비스로 전송되나요?

아니요. 앱은 별도 중계 서버, 광고 SDK, 행동 분석 SDK를 두지 않습니다. 인증 정보는 기기에서 엔트리 서버로 직접 보내는 요청에만 붙습니다. 이 다운로드 페이지도 외부 분석 스크립트나 외부 폰트를 사용하지 않습니다.

기기에는 어떻게 보관되나요?

세션 사본과 토큰은 Android Keystore가 보호하는 키로 암호화합니다. 공식 로그인 WebView도 자동 로그인을 위해 앱 전용 쿠키 저장소를 사용합니다. 과거 평문 세션 값은 이전 후 삭제하고, Keystore 오류 시 평문으로 낮춰 저장하지 않습니다.

영구 알림 보관함의 제목·본문·원본 payload도 Keystore 키를 사용하는 AES-GCM으로 필드 암호화하며 기존 평문 행은 실행 후 암호화 형식으로 이전합니다. 검색과 분류에 필요한 종류·시각·사용자 식별자와 이미지 URL 같은 메타데이터는 Room SQLite에 남으므로, 루팅·잠금 해제 단말에서 모든 알림 메타데이터까지 보호된다고 주장하지 않습니다. 데이터베이스와 파일은 클라우드 백업·기기 이전에서 제외합니다.

로그아웃하면 무엇이 지워지나요?

암호화된 쿠키와 토큰, 남아 있을 수 있는 구버전 평문 세션 값을 지우고 WebView 세션도 종료합니다. 앱 삭제 시 Android 앱 전용 데이터도 함께 삭제됩니다.

공식 로그인 페이지 감시와 리다이렉트는 무엇인가요?

로그인 완료와 세션 갱신을 알아보기 위해 앱 내부 브라우저의 페이지 상태를 확인합니다. 세션을 가진 WebView는 원격 디버깅, 혼합 HTTP 콘텐츠, 제3자 쿠키, 파일 접근을 허용하지 않으며 화면 캡처도 차단합니다. 일반 웹 탐색용 브라우저가 아니라 엔트리 기능 수행을 위한 제한된 실행 환경입니다.

엔트리 페이지에 XSS가 있다면 Entify도 위험한가요?

공식 출처 자체에서 실행되는 XSS를 앱이 완전히 무효화할 수는 없습니다. Entify는 외부 도메인 이동을 차단하고, 레거시 JavaScript 인터페이스를 사용하지 않으며, 메시지를 정확한 HTTPS 출처·최상위 프레임·현재 경로·크기 기준으로 다시 검사합니다. 메시지 채널은 파일이나 임의 Android API를 공개하지 않습니다. 이 조치는 영향 범위를 줄이지만 엔트리 원본 페이지의 취약점을 치료한다는 의미는 아닙니다.

추가로 어떤 방어가 적용되나요?

화면 캡처와 최근 앱 미리보기를 막고, Android 12 이상에서는 다른 앱의 화면 오버레이를 숨기며 가려진 터치를 거부합니다. API·HTML·이미지 응답에는 크기 제한이 있고, 큰 이미지의 픽셀 수와 SVG 위험 선언을 검사합니다. 인증서 고정은 엔트리의 정상 인증서 교체를 장애로 만들 수 있어 적용하지 않고 시스템 인증서만 신뢰합니다.

어떤 Android 권한을 사용하나요?

인터넷은 엔트리 통신, 알림 권한은 새 소식 표시, 포그라운드 서비스, Wake Lock은 백그라운드 확인, 부팅 완료 권한은 사용자가 켠 감시 상태 복원에 사용합니다. 배터리 최적화 제외는 안정적인 주기 확인을 위한 선택 요청입니다.

Play 스토어 앱이 아닌데 설치해도 되나요?

외부 APK에는 Play 스토어 심사가 적용되지 않으므로 경고가 표시되는 것이 정상입니다. 이 페이지와 GitHub 소스를 교차 확인하고 아래 SHA-256이 다운로드 파일과 일치하는지 검증하세요. Play Protect가 악성으로 판단해 차단하면 억지로 우회하지 말고 설치를 중단한 뒤 이슈로 알려주세요.

SHA-256: B52ECDBE60A7D8124672808FCF4483F11A3FDD3ADF0C8D4D264991C29F6AB703서명 인증서 SHA-256: 8905D03BAE430503CE1811C9078C96DC5AD2493BD6999688291A4FE209CE776D
릴리스 서명은 어떻게 관리하나요?

v1.x는 기존 설치자의 업데이트 호환성을 위해 초기 인증서를 유지합니다. 새 운영 키 설정은 별도 빌드 모드로 분리되어 있으며, 키 경로나 비밀번호가 하나라도 빠지면 빌드가 실패합니다. 전용 운영 키로 전환할 때는 기존 앱과 서명이 달라져 재설치 또는 별도 앱 ID가 필요하므로 사전 고지합니다.
