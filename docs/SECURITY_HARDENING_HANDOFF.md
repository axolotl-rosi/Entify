## 의도적으로 남긴 운영 제약

아래 내용은 v1.2.0에서 새로 발견된 버그가 아니라 공개적으로 관리하는 설계·운영 제약입니다.

1. 기존 설치자의 인플레이스 업데이트를 위해 v1.x는 초기 Android Debug 인증서 계보를 유지합니다. 전용 운영 키 전환 계획은 [RELEASE_SIGNING.md](RELEASE_SIGNING.md)에 분리했습니다.
2. 사용자 식별자와 URL 등 검색용 DB 메타데이터는 평문입니다. 제목·본문·원본 payload만 필드 암호화합니다.
3. 공식 엔트리 출처 자체의 XSS, 루팅·후킹된 단말, 손상된 OS를 앱 하나로 완전히 무효화할 수 없습니다.
4. Keystore 이전, 잠금 화면 표시, 제조사별 WebView 동작은 실제 기기 조합에서 계속 회귀 검증해야 합니다.
5. 독립 모바일 침투 테스트나 제3자 보안 인증을 받았다는 의미는 아닙니다.

이 제약의 공격 범위와 완화책은 [THREAT_MODEL.md](THREAT_MODEL.md)에 현재형으로 관리합니다.
