# v1.2.0 보안 구현 교차 검토 기록

>
> 최초 구현 검토: 2026-10-15
>

>
> 이 문서의 항목은 현재 미해결 취약점 또는 새로운 버그 제보가 아닙니다.

이 문서는 Gemini가 먼저 구현한 보안 변경을 Codex가 실제 호출 경로와 대조하고, 발견된 누락을 수정해 v1.2.0으로 배포한 과정을 남긴 사후 기록입니다. 현재 사용자 안내는 [SECURITY.md](../SECURITY.md), 버전별 변경 사항은 [CHANGELOG.md](../CHANGELOG.md)를 기준으로 합니다.

## 최초 구현에서 추가된 보호

- URL과 이미지 호스트 검증을 `EntryOriginPolicy`로 중앙화
- 잠금 화면용 비식별 알림 `publicVersion` 추가
- 원본 payload 민감 키 소거 및 크기 제한
- 알림 제목·본문의 Keystore 기반 AES-GCM 필드 암호화
- 디버깅·테스트 키·일반적인 루팅 흔적을 비차단 경고 신호로 수집하는 `SecurityDiagnostics`
- URL, payload, 암호화, 응답 및 이미지 처리 단위 테스트 추가

|---|---|---|

| `publicVersion`이 서비스 알림 경로에만 적용됨 | `MainActivity`의 사용자 알림 생성 경로 전체에도 적용 | **수정 완료** |
| URL 경로에서 이중 인코딩 우회 테스트가 부족 | 인코딩된 점·슬래시·역슬래시·재인코딩 거부 규칙과 테스트 추가 | **수정 완료** |

## 검증 범위의 한계

Android 기기 조합이 필요한 Keystore 이전, 잠금 화면 렌더링, 제조사별 WebView 동작은 자동화 테스트만으로 외부 인증된 상태가 아닙니다. 이는 수정되지 않은 과거 버그라는 뜻이 아니라, 릴리스마다 실제 기기에서 계속 확인해야 하는 회귀 검증 범위입니다.

최초 인수인계서의 세부 문구와 중간 APK 해시는 Git 이력에서 확인할 수 있습니다. 공개 문서에는 중간 산출물을 최신 릴리스처럼 보이게 하지 않기 위해 최종 상태만 남깁니다.
